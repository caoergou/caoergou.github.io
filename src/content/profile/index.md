这里是我的数字花园 🌱

我的工程底子，是从大数据攒起来的。
搭数据管道，和 Java、海量数据打交道，
那几年教会我什么是好工程。

后来我转向 Python 与全栈，
也一头扎进 LLM 应用。
写着写着，越来越确信——
开发方式，正在被 AI 重新定义。
（私下里，我也是个乐在其中的 vibe coder。）

现在我想把这件事讲给更多人听——
企业该怎么用好 AI？哪些工作流该被 Agent 改变？

坚信好的工程不是炫技。
而是让真正有用的东西，被更多人用起来。

This is my digital garden 🌱

My engineering roots are in big data.
Building data pipelines, working with Java and massive datasets —
those years taught me what good engineering means.

Later I moved to Python and full-stack,
and dove headfirst into LLM apps.
The more I built, the more I became convinced —
the way we build software is being redefined by AI.
(Off the clock, I'm also a vibe coder having a great time.)

Now I want to tell more people about it —
How should enterprises adopt AI? Which workflows should Agents reshape?

I believe good engineering isn't showing off.
It's about getting genuinely useful things into more hands.
